# Electronell
A tool that helps you to take cornell notes! You can export it as PNG or PDF, and the letters in PDF are selectable. 

# Demo
![image](https://github.com/SkewsVetoes11/Electronell/assets/154125603/03be3ecd-cbc8-44f1-8d33-38339931234c)

# How to run locally
1. Clone this repo.
2. Make sure you are on "web-version" branch. I wanted to make an Electron JS project at first but thing went wrong.
3. ```npm install```
4. ```npm run dev```

# Libraries
This project is made possible by TinyMCE, react-to-print and so on.
